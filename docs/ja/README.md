# dot-agents ドキュメント

[English](../en/README.md) | 日本語

## 概要

このディレクトリ（`docs/ja/`）は、dot-agents の日本語のドキュメントの置き場です。この README はその入口であり、どのドキュメントに何が書かれているかを案内する目次の役割を持ちます。

ただし、以下のような内容は扱っていません。

- dot-agents の紹介や、導入・更新のおおまかな手順（詳しくは、リポジトリルートの [README.ja.md](../../README.ja.md) を参照してください）
- ルールの本文そのもの（詳しくは、リポジトリルートの `rules/` と `agents-md/` を参照してください）

## ドキュメント一覧

各ドキュメントは 1 つのテーマだけを扱います。

| ファイル | 何が書かれているか | 読むべき人・状況 |
| --- | --- | --- |
| [cli.md](./cli.md) | 各コマンドとオプション、反映されるファイル、設定ファイルの項目 | CLI の細かい動作を知りたい人、コマンドが止まった理由を知りたい人 |
| [rules.md](./rules.md) | ルールの分け方（core / lang / stack）、モジュールの一覧、ルールの書き方の方針と追加の手順 | どのルールが反映されるかを知りたい人、ルールを追加・変更したい人 |

新しいドキュメントを追加する際は、この一覧にも 1 行追加し、目次としての役割が保たれるようにしてください。
