# dot-agents Documentation

English | [日本語](../ja/README.md)

## Overview

This directory (`docs/en/`) holds the English documentation for dot-agents. This README is its entry point and serves as a table of contents that shows what each document covers.

The following topics are not covered here:

- An introduction to dot-agents and the overall steps for setting it up and updating it (see [README.md](../../README.md) at the repository root)
- The rules themselves (see `rules/` and `agents-md/` at the repository root; they are written in Japanese)

## Documents

Each document covers a single topic.

| File | What it covers | Who should read it |
| --- | --- | --- |
| [cli.md](./cli.md) | Each command and its options, the files that are reflected, and the fields of the configuration file | Anyone who wants to know the details of the CLI, or why a command stopped |
| [rules.md](./rules.md) | How the rules are organized (core / lang / stack), the list of modules, and the guidelines and steps for writing rules | Anyone who wants to know which rules are reflected, or who wants to add or change rules |

When adding a new document, add a row to this table as well so that this README keeps working as a table of contents.
